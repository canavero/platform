    Plataformas 2026.2 — Projeto Store

    • Alunos: Enzo Urioste Canavero e Miguel Fernandes Oliveira Damásio
    • Grupo: dupla Miguel Damásio + Enzo Canavero (4 microsserviços: Gateway, Auth, Account e Exchange)
    • Avaliação: checklist da rubrica, item por item, com as evidências
    • Disciplina: Plataformas — Insper, 2026.2
    • IA: feito com Claude Code — ver Uso de IA

    Plataforma de microsserviços Spring Boot 4.1 / Java 25 para uma loja (compra e venda de produtos), com API Gateway (Spring Cloud Gateway), autenticação JWT, gestão de contas (PostgreSQL) e câmbio de moedas (API de terceiros), empacotada em Docker, orquestrada no Kubernetes (Amazon EKS), com CI/CD no GitHub Actions, bottlenecks implementados (cache Redis, circuit breaker/retry, rate limiting, observabilidade, varredura de vulnerabilidades, autoscaling), teste de carga com HPA e análise de custos.

    flowchart LR
    user([Usuário]) -->|HTTP| lb[Load Balancer<br/>AWS ELB]
    lb --> gw
    subgraph eks [Kubernetes — trusted layer]
        gw[gateway] -->|/auth/**| auth
        gw -->|/accounts/**| account
        gw -->|/exchanges/**| exchange
        auth -->|Feign| account
        account --> db[(PostgreSQL)]
        account -.cache.-> redis[(Redis)]
        exchange -.cache.-> redis
        gw -.rate limit.-> redis
    end
    exchange -->|HTTPS| api[[AwesomeAPI<br/>cotações]]
