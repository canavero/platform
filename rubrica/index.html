    Rubrica do projeto (peso)

    Item Peso O que entregamos Evidência
    Gateway 5 % Spring Cloud Gateway (WebFlux): rotas, filtro JWT que chama POST /auth/solve, remove o id-account vindo do cliente, rate limiting no Redis Gateway · gateway-service
    Auth 5 % registro, login com JWT em cookie HttpOnly, /auth/me, /auth/solve; circuit breaker para o account Auth · auth + auth-service
    Account 5 % CRUD de contas, JPA + Flyway no PostgreSQL, senha com hash, cache Redis Account · account + account-service
    Exchange 5 % cotações da AwesomeAPI com cache, retry e circuit breaker; id-account vindo do token Exchange · exchange + exchange-service
    Bottlenecks 20 % 6 implementados e medidos: cache Redis, circuit breaker + retry, rate limiting, observabilidade (Prometheus + Grafana), Trivy no CI, HPA; 2 em destaque por integrante Bottlenecks · dashboard no Grafana · vídeo
    AWS 5 % conta do grupo com SSO, AWS CLI, roles IAM do cluster e dos nós, VPC pelo CloudFormation com o template do enunciado AWS e EKS · Runbook
    EKS 10 % deploy real (15/11/2026): cluster eks-store, imagens no ECR, ELB público, Secrets/ConfigMaps, probes, HPA; smoke test 14/14 pelo ELB; ambiente reduzido ao mínimo e destruído AWS e EKS · evidências
    CI/CD (GitHub Actions) 10 % pipeline por serviço (build + testes → imagem multi-arch + Trivy → deploy no EKS por OIDC), E2E da plataforma (compose + smoke test) e publicação das docs CI/CD · execuções verdes no GitHub Actions
    Load Testing 15 % busybox do enunciado (HPA do gateway 1 → 10 no EKS), k6 pelo ELB (2.215 req/s, 0 % de erro em /info), vídeo do teste com o HPA Teste de carga
    PaaS, custos e SLA 10 % preços da AWS Price List, cenários A0/A/C, otimizações aplicadas (−38 %/h), custo real do deploy, PaaS usados, SLA composto, SLO/SLI Custos, PaaS e SLA
    MkDocs 10 % este site (Material for MkDocs, GitHub Pages), com diagramas Mermaid, código incluído dos submódulos e uso de IA documentado Uso de IA

    Custo de AWS

    Usamos o mínimo de AWS: só uma conta e uma região, e cada recurso com o teardown já planejado. O deploy real ficou ligado ≈ 4,6 h e custou ≈ US$ 1,15 no pior caso. As otimizações derrubaram o custo por hora em 38 % (Spot, 1 NAT, sem RDS, ECR com lifecycle), e o vídeo do HPA foi gravado num Kubernetes local (kind) com os mesmos manifests, sem gastar AWS.
